01 마크다운이 뭔가요?

마크다운은 그냥 텍스트 파일입니다. 워드나 한글처럼 마우스로 클릭해서 굵게, 제목 크기 조절 같은 서식을 주는 대신, #이나 * 같은 간단한 기호를 글자 앞뒤에 붙여서 서식을 표현합니다.

예를 들어 **중요**라고 쓰면 화면에는 중요라고 굵게 표시됩니다. 파일 확장자는 .md입니다.

02 기본 문법

표준 마크다운에서 가장 많이 쓰이는 문법입니다.

제목

#을 앞에 붙이면 제목이 됩니다. 개수가 많을수록 작은 제목입니다.

# 제목 1 (가장 큼)
## 제목 2
### 제목 3
sample.md 실제 예시### 2026년 중기부 3차 수출바우처 협약체결 기간 안내

강조 (굵게 / 기울임)

**굵게 쓸 텍스트**
*기울임으로 쓸 텍스트*

목록

- 항목 1
- 항목 2

1. 첫 번째
2. 두 번째

- [ ] 체크 안 된 항목
- [x] 체크 된 항목
sample.md 실제 예시- [ ] 레이아웃: table 기반, 최대 600~680px
- [ ] 스타일: 모든 CSS 인라인 처리

링크 / 이미지

[여기를 클릭](https://example.com)
![대체 텍스트](이미지주소.jpg)

표 (테이블)

| 항목 | 내용 |
|---|---|
| 공고명 | 수출지원기반활용사업 참여기업 모집 |
| 주관 | 산업통상자원부 |

첫 줄은 열 제목, 둘째 줄 |---|---|은 반드시 있어야 표로 인식됩니다.

세로로 병합된 셀 표기 (〃)

원본 자료(엑셀, PPT 등)에서 여러 행에 걸쳐 같은 값을 가진 셀(세로 병합)이 있으면, 값이 바뀌는 첫 행에만 쓰고 이어지는 행에는 〃(같은 값) 기호를 씁니다.

| 지원분야 | 내용 |
|---|---|
| 조사/일반컨설팅 | ... |
| 〃 | 디자인개발 |
| 〃 | 브랜드개발·관리 |

표 바로 아래에 > ※ 〃 는 바로 위 행과 같은 값입니다. 각주를 한 줄 추가해서 표기 의미를 밝혀주세요.

행 전체를 강조하고 싶을 때

셀 내용 전체를 **굵게**로 쓰면, 변환 시 그 행 전체에 옅은 주요색 음영이 들어갑니다.

| 항목 | 내용 |
|---|---|
| 공고명 | 수출지원기반활용사업 참여기업 모집 |
| **마감일** | **2026년 9월 17일까지** |

인용구 & 구분선

> 이 모든 것이 함께 설계되어야 합니다

---

>는 인용구(강조 문구) 박스, ---은 가로 구분선입니다.

03 이 프로젝트 전용 규칙

sample.md는 표준 마크다운에 더해, 뉴스레터를 이메일로 변환하기 위한 자체 규칙을 씁니다. 핵심은 두 가지입니다.

  1. —가 아니라 ---로 섹션을 나눕니다. 뉴스레터 한 편은 여러 섹션(블록)으로 이루어지고, 각 섹션은 ---로 구분합니다.
  2. 각 섹션 맨 위에 ## type: 키워드를 붙여 섹션 종류를 알려줍니다.

기본 틀

---

## type: body
여기에 본문 내용을 씁니다.

---

사용 가능한 type 키워드

키워드언제 쓰나요
hero뉴스레터 맨 위, 가장 크게 보여줄 헤더
body일반 본문 텍스트
info-box날짜·기한처럼 강조할 정보 박스
cta클릭을 유도하는 버튼 영역
card-list아이콘 + 텍스트 카드 목록
highlight강조하고 싶은 한두 문장
box배경 카드 안에 담을 내용
footer맨 하단 마무리 문구
table표 형태 데이터
timeline순서가 있는 절차/프로세스
notice유의사항, 경고, 규정 안내

보조 필드

- emoji: 📢 대표 이모지, - button: 문구 버튼처럼 보일 텍스트를 지정합니다.

sample.md 실제 예시## type: cta
### 📞 수출 전략 컨설팅 문의
- button: 02-6265-2100 (내선2번)

04 따라 써보는 미니 예제

섹션 3개짜리 아주 짧은 뉴스레터를 직접 작성해봅니다.

---

## type: hero
### 가을맞이 신제품 안내
지금 바로 확인해보세요!
- emoji: 🍂

---

## type: body
안녕하세요, 고객님.
이번 가을 새롭게 출시된 제품을 소개해 드립니다.

---

## type: cta
### 📞 자세히 문의하기
- button: 02-1234-5678

---
  1. ---로 섹션 시작
  2. ## type: 키워드로 섹션 종류 지정
  3. ### 소제목 + 본문 내용 작성
  4. 필요하면 - emoji: 또는 - button: 추가
  5. 다음 섹션도 ---로 구분해서 반복

05 자주 하는 실수 체크리스트

  • 섹션 사이에 ---를 빠뜨리지 않았나요?
  • ## type: 키워드 철자가 정확한가요?
  • 표를 쓸 때 |---|---| 구분선을 빠뜨리지 않았나요?
  • - button:, - emoji: 앞에 하이픈과 띄어쓰기를 정확히 넣었나요?
  • 파일 확장자가 .md인가요?
같은 내용을 프로젝트 폴더의 GUIDE.md 파일에서도 확인할 수 있습니다.
